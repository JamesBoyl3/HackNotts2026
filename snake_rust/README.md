# Snake Game — Rust edition

A desktop Snake game translated from the supplied Python/Tkinter version, using Rust and `eframe/egui`.

## Features
- 10 × 10 grid
- Green snake and red food on a dark background
- Arrow keys or WASD controls
- Score increases by 10 for each food item
- Wall and self-collision detection
- Game-over / win overlay
- Press `R` to restart and `Q` to quit

## Run

Install Rust/Cargo, then run from this directory:

```bash
cargo run
```

The first build downloads and compiles dependencies and may take several minutes.
